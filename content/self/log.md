Today I made an index page for self/log.

The idea for log page is to have one big page that feed from log entries.
For now I just manually type every entry in the index page,
later we can add processing between read and render.

The whole idea is revolving around tokens and parser --- if that is
the correct words. Later we can put some directive inside the source,
whether it's block-level or inline-level, and then in the processing
those directives can be translated by artifact and just do what it has to do.

It's still a concept, the whole artifact too. 
But it's nice to have some direction, so we can have a nice roadmap.
It's going to be different, but it is what it is.
