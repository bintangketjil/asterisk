Decision

Lately I was wondering if my current workflow is any good or not for my needs, especially for writing this pages. I don’t want to write html by hand and I don’t think Markdown-only could give me the same thing I have in mind. And I also don’t want to invent another document format just for some small features.

What I want to do is to be able to read and maintain the source — keep it clean — while also can do all sort of things with it, styling wise. I want to be able to group elements, easily applying tags/class, and customizing document hierarchy whether it is semantically correct or not.

It’s such a downer to have to write some awkward syntax just to get nested elements, or make some layout. And there is no way to have both with my current workflow.

I think we need to do some changes, either to keep the sources clean and minimalist output, or to change how we see the whole picture, recognizing what I want to do and how to get that.

We can create some structure from patterns I usually do when tyring to write or style it. I don’t have the idea, yet. Bu I think it’s a good start.
